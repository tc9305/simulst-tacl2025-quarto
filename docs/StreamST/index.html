兩篇論文的名稱用法

StreamAtt，ACL 2024：摘要把 SimulST 描述為處理預切語音，以 continuous、unbounded streams 定義 StreamST。閱讀原文

TACL 2025：使用較廣的 SimulST 框架，指出預切輸入是多數研究的簡化設定，並以輸入、架構及輸出策略分類。閱讀原文

這是兩篇論文的用語範圍差異，不能視為整個領域固定的二分法。本站的資料夾名稱是研究整理方式。
